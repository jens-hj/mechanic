# UI fonts

Mechanic uses Chakra Petch for display titles and section headings, with
JetBrains Mono for body copy, controls, labels, and numeric readouts.

The font binaries and OFL license texts come from the official Google Fonts
repository:

- <https://github.com/google/fonts/tree/main/ofl/chakrapetch>
- <https://github.com/google/fonts/tree/main/ofl/jetbrainsmono>
